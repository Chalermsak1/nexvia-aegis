The adapter JSON-copies an explicit supported configuration, requires its exact key set to match the benchmark signature (excluding environment/instrumentation), records it before START, then passes that same map into the actual benchmark call. Callback arguments cannot be supplied through this map. This removes a caller-side mismatch opportunity; it does not authenticate execution or external state.

The ledger is created and START persisted before environment construction. An instrumented subclass records the actual reset state/model timestep/configuration/integrator/gravity before decisions. Decision and physics callbacks append incrementally, including actual time, timestep and environment/physical-phase label. RESET is identified as refreshed for both environments; subsequent legacy position/velocity observations retain their mixed-phase label. Transition CBF residuals remain pre-integration diagnostics in the original record and must not be interpreted as post-state certificates.

Source hashes are recorded before and after successful execution; drift is retained as ERROR with no retry. Ordinary execution exceptions produce ERROR; persistence/ledger errors propagate without terminal retry. No existing output is resumed or overwritten. A crash between physics and append can still leave an unrecorded step. Hashes and metadata are self-reported, not independent authentication or rollback protection.
