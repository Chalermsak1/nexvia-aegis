### 📌 Key Narrative (เนื้อหาหลัก)

* **Heuristic Thresholds แตกเมื่อเจอ Edge Cases:** การตั้งค่าเกณฑ์ความมั่นใจแบบตายตัว ไม่สามารถปรับตัวตามสภาพแวดล้อมที่เปลี่ยนไปได้ และมักเกิดภาพหลอนของความมั่นใจ (Hallucinated Certainty)
* **Conformal Prediction แบบเดิมใช้กับการบินจริงไม่ได้:** Batch CP พึ่งพาสมมติฐาน Exchangeability (ข้อมูลต้องสุ่มอิสระ) แต่การบินตรวจสอบจริงเป็นข้อมูลอนุกรมเวลาที่มีความเชื่อมโยงกันอย่างต่อเนื่อง และหุ่นยนต์มีสิทธิ์หยุดตรวจเมื่อใดก็ได้ (Adaptive Stopping) ซึ่งทำให้ขอบเขตความเชื่อมั่นพังทลายทันที
