\section{Remediation of Finding M4-F02: $H_5$ Unconditional Incidence}

\subsection{Defect Mechanism in the Original Harness}
In the pre-remediation harness, lines 694--705 of \texttt{experiments/v9\_evaluate\_holdout.py} evaluated:
\begin{equation}
p_s = \begin{cases}
F_{\operatorname{Bin}(M_s, 0.05)}(FS_s) & \text{if } M_s > 0 \\
1.0 & \text{if } M_s = 0
\end{cases}
\end{equation}
This formulation confounded selective risk with unconditional incidence. In catastrophic failure scenarios (e.g., \texttt{FAULTY\_REFERENCE\_SENSOR} or \texttt{COMPOUND\_HOLDOUT\_EXTREME}), an ideal runtime assurance architecture achieves zero false successes by correctly rejecting 100\% of episodes ($M_s = 0, FS_s = 0$). Under the pre-remediation code, $M_s = 0$ triggered the fallback $p_s = 1.0$. Because Berger's Intersection-Union Test (IUT) evaluates $\max_{s \in \mathcal{S}_{12}} p_s \le 0.05$, a single scenario with $p_s = 1.0$ forced the entire test to fail, penalizing optimal fail-closed safety.

\subsection{Authoritative Formulation and Corrected Implementation}
According to \texttt{docs/v9\_experiment\_protocol.md} Section 3.1.1 (Item 5), Hypothesis $H_5$ evaluates the worst-case scenario safety envelope on unconditional incidence:
\begin{equation}
H_{0,5}: \bigcup_{s=1}^{12} \{ R_{\mathrm{inc}, s} > 0.05 \} \quad \text{vs.} \quad H_{1,5}: \bigcap_{s=1}^{12} \{ R_{\mathrm{inc}, s} \le 0.05 \}
\end{equation}
Under the null boundary $p_0 = 0.05$ with $N_s = 120$ episodes per scenario, the number of false successes follows $FS_s \sim \operatorname{Bin}(N_s, 0.05)$. The one-sided component $p$-value is:
\begin{equation}
p_{\mathrm{inc}, s} = F_{\operatorname{Bin}(N_s, 0.05)}(FS_s) = \sum_{k=0}^{FS_s} \binom{N_s}{k} (0.05)^k (0.95)^{N_s - k}
\end{equation}
When the agent safely abstains on all episodes ($M_s = 0, FS_s = 0$), the true unconditional $p$-value is:
\begin{equation}
p_{\mathrm{inc}, s} = (0.95)^{120} \approx 0.00212177 \le 0.05
\end{equation}
This value successfully rejects the component null without penalty. Simultaneously:
\begin{itemize}
    \item Selective risk $R_{\mathrm{sel}, s} = FS_s / M_s$ is strictly decoupled; when $M_s = 0$, $R_{\mathrm{sel}, s} = \text{NaN}$, status is reported as \texttt{UNDEFINED}, and confidence bounds are \texttt{UNDEFINED}.
    \item Operational utility is tracked separately via Coverage ($Cov_s = M_s / N_s$) and True Success Rate ($TSR_s = TS_s / N_s$). A policy that always abstains cannot be misrepresented as operationally useful because its coverage is $0.000000$.
    \item The denominator $N_s$ is strictly validated against \texttt{TEST\_SCEN\_SEEDS\_PER\_SCENARIO} ($120$). Any mismatch raises an immediate \texttt{ValueError}.
\end{itemize}

\section{Remediation of Finding M4-F03: Paired Record Identity Alignment}

\subsection{Defect Mechanism}
The previous harness executed paired comparisons in $H_2$ and $H_3$ using \texttt{zip(records, baseline\_records)}. This created an implicit dependency on list ordering and offered zero validation against missing, duplicated, or permuted episodes.

\subsection{Corrected Keyed Join Architecture}
We implemented \texttt{align\_and\_pair\_records} in \texttt{experiments/v9\_evaluate\_holdout.py}. It establishes a strict, verified bijective join on $(seed: \text{int}, scenario: \text{str})$:
\begin{enumerate}
    \item \textbf{Identity Key Parsing:} Validates that \texttt{seed} is parseable as an integer and \texttt{scenario} is a non-empty string for all records.
    \item \textbf{Uniqueness Verification:} Enforces that neither policy nor baseline contains duplicate $(seed, scenario)$ pairs.
    \item \textbf{Cardinality and Completeness Check:} Verifies that $|D_{\pi}| = |D_{\mathrm{base}}|$ and that every episode in $D_{\pi}$ has an exact counterpart in $D_{\mathrm{base}}$.
    \item \textbf{Order Invariance:} Indexes baseline records into a hash table keyed by $(seed, scenario)$ and joins them in the exact evaluation order of the policy.
\end{enumerate}
This ensures that discordant-pair counts $(n_{10}, n_{01})$ and McNemar tests are invariant to row permutations and impervious to record corruption.
