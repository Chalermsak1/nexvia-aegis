\begin{abstract}
\noindent This report provides the formal verification of the NEXVIA AEGIS Milestone V9-M4 execution harness using an injectable synthetic simulator (\texttt{MockHoldoutSimulator}) and isolated end-to-end test fixtures. We evaluate the entire execution pathway without touching production holdout partitions or consuming reserved RNG seeds. Across 15 newly developed and rigorous unit and integration tests (\texttt{test\_30} through \texttt{test\_44} in \texttt{tests/test\_v9\_holdout\_preflight.py}), we confirm: (1)~Common Random Numbers determinism across V9, V8.1, and V7 controllers; (2)~fail-closed execution authorization barrier; (3)~complete synthetic mixture holdout evaluation ($H_1, H_2, H_4$); (4)~complete synthetic scenario holdout evaluation ($H_3, H_5$ across 12 stratified scenarios); (5)~single-shot output protection and mid-run failure containment; (6)~outcome algebra verification and fail-unsafe crash accounting; (7)~undefined selective risk handling when accepted coverage is zero; and (8)~manifest and policy tampering detection. All 44 tests in the focused preflight suite and all 155 tests in the full repository regression suite passed with zero failures.
\end{abstract}

\section{Mock Simulator Design and Failure Injections}

The test harness incorporates \texttt{MockHoldoutSimulator} in \texttt{experiments/v9\_evaluate\_holdout.py}, which provides deterministic, reproducible synthetic simulation:
\begin{itemize}
    \item \textbf{Pseudorandom Coupling:} Consumes floats from \texttt{rng\_env} and \texttt{rng\_sensors} derived via \texttt{\_derive\_episode\_rngs}, ensuring that V9, V8.1, and V7 evaluate identical environmental disturbances.
    \item \textbf{Failure Injections:} Supports targeted injections via constructor parameters:
    \begin{itemize}
        \item \texttt{inject\_crash\_keys}: Forces crash events ($crashed=1$) with fail-unsafe penalization ($A=0, TS=0, FS=1$).
        \item \texttt{inject\_timeout\_keys}: Forces horizon expiration ($timed\_out=1$).
        \item \texttt{inject\_abstain\_keys}: Forces safety filter abstention ($abstain=1$).
        \item \texttt{inject\_algebra\_violation\_keys}: Injects invalid outcome tuples to test algebraic guards.
        \item \texttt{inject\_runtime\_exception\_keys}: Injects simulation errors to test partial CSV dumping and \texttt{INCOMPLETE\_INVALID.json} generation.
        \item \texttt{scenario\_overrides}: Overrides scenario behavior, such as forcing zero accepted episodes ($M_s=0$).
    \end{itemize}
\end{itemize}

\section{Statistical and Artifact Reconciliation}

\subsection{Mixture Holdout Reconciliation}
Under synthetic mixture evaluation ($N=100$ in \texttt{test\_33}):
\begin{itemize}
    \item The policy achieved $M = 92$ accepted decisions and $FS = 2$ false successes, yielding point estimate $\hat{r} = 2 / 92 \approx 0.0217$. The 1-sided 95\% Clopper--Pearson upper bound was $0.0577 > 0.05$, yielding correct non-rejection of $H_1$ under synthetic data.
    \item $H_2$ McNemar contingency counts versus V8.1 and V7 were calculated exactly from paired records.
    \item $H_4$ coverage floor $\hat{c} = 92 / 100 = 0.92 \ge 0.35$ was confirmed.
    \item All episode and baseline CSV digests were cryptographically summarized into \texttt{integrity\_sha256}.
\end{itemize}

\subsection{Scenario Holdout Reconciliation}
Under synthetic scenario evaluation ($12 \times 10 = 120$ episodes in \texttt{test\_34}):
\begin{itemize}
    \item $H_3$ paired TSR difference $\Delta\text{TSR} = \text{TSR}_{\text{V9}} - \text{TSR}_{\text{V8.1}}$ was computed on the 10 nominal/adversarial scenarios, validating both the 1-sided 95\% LCB and the nominal TSR threshold ($\ge 0.94$).
    \item $H_5$ Berger IUT evaluated unconditional binomial test p-values on $N_s = 10$, correctly identifying $\max_s p_s$ and applying Holm--Šidák sequential break stopping.
    \item When $M_s = 0$ was injected for scenario \texttt{CORRUPTED\_ANCHOR\_STRESS} in \texttt{test\_40}, the breakdown reported selective risk as \texttt{UNDEFINED} (null in JSON / NaN in CSV) without numeric failure.
\end{itemize}
