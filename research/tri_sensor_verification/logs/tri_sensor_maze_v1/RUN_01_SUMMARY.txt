1. OBJECTIVE
------------
Evaluate a self-verifying three-sensor localization layer (Tri-Sensor Verifier)
designed to cross-check independent sensors operating in the same physical
environment, isolate faulty channels under drift or sensor failures, strictly
exclude corrupted readings from both operator display and robot control outputs,
and fail closed when no verified sensor majority exists.

2. EXPERIMENTAL SETUP
---------------------
- Environment: 3D subterranean maze (10.0 x 10.0 x 2.5 m, 5 static pillars,
  0.25 m voxel resolution, Frontier Exploration planner, 45 steps/episode,
  deterministic random seeds).
- Independent Sensor Channels:
    * S1_VIO   : Visual-Inertial Odometry   (nominal sigma = 0.030 m)
    * S2_LIDAR : LiDAR Scan-Matching        (nominal sigma = 0.035 m)
    * S3_UWB   : UWB + IMU Fusion           (nominal sigma = 0.045 m)
- Evaluated Arms (20 scenarios x 3 arms = 60 full maze episodes):
    1) NAIVE_AVG            : Unverified mean across all finite channels.
    2) TWO_SENSOR_MIN_SIGMA : Two-sensor fallback selecting the lowest nominal
                              sigma channel on mismatch (baseline reference).
    3) TRI_SENSOR_VERIFIER  : Proposed four-layer self-verification architecture:
                              (a) Physical validity and arena bounds guard,
                              (b) Retimestamped-freeze detector (fresh metadata
                                  with static physical output),
                              (c) Pairwise normalized disagreement and
                                  deterministic Page CUSUM (k = 1.65, h = 4.0;
                                  note: Page CUSUM reflects at zero and is NOT
                                  a Ville-anytime-valid supermartingale),
                              (d) Majority consensus isolation, inverse-variance
                                  fusion of healthy channels, quarantine audit
                                  separation, and fail-closed abstention.
- Fault Matrix:
    * NOMINAL (1 scenario)
    * GRADUAL_DRIFT, HEAVY_DRIFT, SUDDEN_BIAS, OUTLIER_BURSTS,
      RETIMESTAMPED_FREEZE, SENSOR_BLACKOUT (tested individually on S1, S2, S3;
      18 scenarios)
    * DUAL_S1_DRIFT_S2_FREEZE (simultaneous dual-sensor stress counterexample;
      1 scenario)

4. KEY SCENARIO HIGHLIGHTS
--------------------------
- Heavy Drift on Primary Sensor (S1_VIO):
    TWO_SENSOR_MIN_SIGMA RMSE = 3.278 m vs. TRI_SENSOR_VERIFIER RMSE = 0.043 m
    (isolated in 1 step, 97.0% isolation accuracy, 0 collisions).
- Retimestamped Freeze on S1_VIO (fresh timestamps with frozen values):
    TWO_SENSOR_MIN_SIGMA RMSE = 4.408 m vs. TRI_SENSOR_VERIFIER RMSE = 0.049 m
    (isolated in 1 step across S1, S2, and S3; 97.0% isolation accuracy).
- Sudden Static Bias & Sensor Blackout (S1, S2, S3):
    100.0% isolation accuracy with 0-step instant rejection; RMSE = 0.036-0.045 m.
- Dual Simultaneous Failure Counterexample (S1 Heavy Drift + S2 Freeze):
    NAIVE_AVG RMSE = 1.738 m, TWO_SENSOR_MIN_SIGMA RMSE = 2.974 m.
    TRI_SENSOR_VERIFIER entered FAIL_CLOSED_ABSTAIN (32 safe-stop steps),
    withholding unverified coordinates from display and control (0 collisions;
    displayed-tick RMSE = 0.045 m).

5. IDENTIFIED LIMITATIONS & NEXT STEPS (FOR RUN #2)
---------------------------------------------------
1) CUSUM Spike-Poisoning on Intermittent Outliers:
   In OUTLIER_BURSTS scenarios (S1, S2, S3), false alarm rates reached
   50.0%-69.2% (compared to 0.0% in all other 17 scenarios). Large single-tick
   outliers (2.4 m) saturate the Page CUSUM accumulator near its cap (40.0),
   keeping the sensor quarantined across subsequent clean ticks while CUSUM
   decays slowly. Planned mitigation for Run #2: decouple instantaneous spike
   gating from the Page CUSUM drift input via Winsorized/clipped residuals.
2) Gradual Drift Detection Latency:
   Slow linear drift (0.030 m/step) required 5-6 steps to exceed the CUSUM
   alarm threshold (isolation accuracy = 81.8%, max display error <= 0.113 m),
   reflecting the fundamental noise-floor sensitivity trade-off.
3) Evidence Scope:
   All results derive from deterministic synthetic simulation with idealized
   sensor noise models. Real-world sensor correlation, clock skew, unmodeled
   dynamics, and hardware-in-the-loop validation remain outside this run's scope.
